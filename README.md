# 複習網

**複習網｜公開教學資料離線典藏**

## 關於複習網

「複習網」原為提供大眾學習、複習與查閱教學資料的公開網站，收錄多年累積的課程內容與相關資料。

依混元禪師生前的交代，希望這些原本公開的教學資源能夠持續保存，並讓有需要的人自由取得、閱讀與學習。

本專案以保存既有資料為主要目的，不再提供原網站的動態服務。

## 資料內容

本典藏保留原網站的主要內容，包括：

- 公開教學課程與相關文章
- 課程複習與參考資料
- 網頁中的圖片及相關附件
- 原網站的文章連結與瀏覽架構

為保護隱私及避免公開不適合再散布的資料，部分原網站檔案已於整理過程中移除，因此少數舊連結可能無法使用。

## 下載與使用

請前往本專案的 **Releases** 頁面，下載最新版本：

**hunyuan-v1.0.zip**

使用方式：

1. 下載 ZIP 壓縮檔。
2. 將檔案完整解壓縮至電腦中的資料夾。
3. 進入解壓縮後的 `yju` 目錄。
4. 使用 Chrome、Edge、Firefox 等瀏覽器開啟 `index.html`。
5. 即可在不連接網際網路的情況下閱讀已保存的網站內容。

不需要安裝任何軟體或架設網頁伺服器。

**注意：** 原網站部分功能需要資料庫或伺服器支援，已無法在離線版本中運作。部分外部網站連結仍需要網路連線。

## 版本資訊

### v1.0 — 2026 年 10 月

首次公開發布離線典藏版本。

- 將原網站內容轉換為靜態 HTML
- 保留主要文章、圖片及網站瀏覽架構

## 資料保存說明

本典藏以保存原有公開教學內容為原則，盡可能維持原始文章與資料的內容及呈現方式。

部分網頁可能因原網站技術、外部資源失效或檔案移除，而出現顯示不完整或連結無法使用的情況。

本典藏不保證所有原網站功能均可使用，也不代表所有內容均已更新至最新版本。
